## 四、本轮修掉的 5 个真实缺陷

### 1. 导出 PNG 必然失败（`SecurityError: Tainted canvases`）

- 现象：导出 PNG 永远不成功，控制台报画布被污染。
- 根因：旧实现走「克隆 DOM → 塞进 `<foreignObject>` 生成 SVG → 画进 canvas → `toDataURL`」。Chrome 对**任何含 `foreignObject` 的 SVG** 都按污染处理，与是否有外链样式无关（已用最小探针确认：纯 rect 通过、`foreignObject` 必抛）。
- 修复：整文件重写为「遍历 `.stage` 重画成纯 SVG」——按 `getBoundingClientRect()` 折算成 `<rect>`/`<circle>`/`<text>`、内联图标用 `<g transform>` 搬运、底图 `<image>` 引用、空白容器补虚线框；导出去掉编辑态辅助层。
- 顺带：新增 SVG 矢量导出（可再编辑）。

### 2. 连线永远命中不到元件

- 现象：连线模式下从元件拖到元件没有任何反应。
- 根因：元件 id 挂在**内容节点 `.view-element`** 上，而 `[data-mr-el="true"]` 外壳本身没有 id；`elementAt()` 只按 `closest('[data-mr-el]')` 取 id，取到空串 → 永远返回 `null`。
- 修复：新增 `resolveId(dom)`——先看节点自身 id 是否在盒子里，再在其所在 `[data-mr-el]` 外壳内找第一个登记过的 id 节点。修复后拖动即落 `page.links`。

### 3. 隐藏元件在设备清单里量成 0×0

- 现象：`隐藏` 的元件导出清单时宽高为 0。
- 根因：隐藏元件 `getBoundingClientRect()` 全 0，`getElementBox` 拿到 `{width:0,height:0}` 就直接返回。
- 修复：量到宽或高为 0 时，保留量到的 left/top，用模型尺寸（`node.width/height`）补齐。实测该行恢复 300×396 px / 6000×7920 mm。

### 4. 导出图混入编辑态浮层文案

- 现象：导出的 PNG 里出现「从元件拖到另一个元件即可连线 · 删除选中的连线」。
- 根因：导出器的跳过清单里没有连线层的操作提示条。
- 修复：`SKIP_SELECTOR` 增加 `.link-layer__tips`；重新构建、重新导出确认文案消失。

### 5. 构建缓存让「改完源码打不进包」（排障关键）

- 现象：改完源码、`npm run build:prod` 显示 `Build complete.`，但产物哈希与内容都不变，浏览器里表现也还是旧行为；同时系统里残留多个 `node build/build.js` 僵尸进程。
- 根因：`build/webpack.base.conf.js` 里 `babel-loader?cacheDirectory`，缓存键基于文件 mtime；本环境下编辑后源文件 mtime 可能早于缓存条目（`LinkLayer.vue` 实测 mtime 19:51 而编辑发生在 20:06），命中旧条目 → 旧代码被复用。另有历史构建进程占用日志文件、写入 dist 互相干扰。
- 处理：`Remove-Item -Recurse -Force node_modules\.cache, dist` → 单进程重新构建 → 逐文件回查产物文本确认命中新代码（`resolveId` / `link-layer__tips` 都在 `chunk-2faf.9ca4179f.js` 中）。
- **教训（写进流程）**：本项目不要用「构建成功」当验证终点，必须核对 `dist/static/js/app.*.js` 与相关 chunk 的**哈希/时间戳**并回查关键标识符。

## 五、已知残留（如实记录，未做）

1. **远端加载/保存未接入**：仍是本地快照（`localStorage`），无服务端工程库（承 P0 结论）。

8. **`getComputedProp` 对未挂载元素仍无兜底**（承 P0）。
